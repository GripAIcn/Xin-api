# web

Xin-api 控制面板前端，基于 React 19 + Vite + shadcn/ui 构建。

## 推荐的 IDE 配置

[VS Code](https://code.visualstudio.com/) + [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)

## 自定义配置

参考 [Vite 配置文档](https://vite.dev/config/)。

## 项目设置

```sh
bun install
```

### 编译并热重载开发

```sh
bun run dev
```

### 类型检查、编译并压缩用于生产环境

```sh
bun run build
```

### 使用 [ESLint](https://eslint.org/) 进行代码检查

```sh
bun run lint
```
