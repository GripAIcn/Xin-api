# Xin-api
LLM API统一管理、全链路追踪与智能分发于一体的轻量级网关服务。系统无缝兼容OpenAI、Anthropic Claude、DeepSeek等主流大模型，实现统一API适配，一套协议对接所有模型，无需重复开发适配。
Lightweight gateway for unified LLM API management, full-link tracing and smart distribution. Compatible with OpenAI, Anthropic Claude, DeepSeek and other mainstream LLMs, enabling unified API access with one protocol.
