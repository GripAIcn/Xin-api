# Xin-api
Xin API 是集大模型 API 统一管理、全链路追踪、智能分发于一体的高性能网关服务。无缝兼容 OpenAI、Anthropic Claude、DeepSeek 等主流大模型，实现标准化统一 API 接入。
Xin API is a high‑performance gateway for unified LLM API management, full‑link tracing and smart distribution. Compatible with OpenAI, Claude, DeepSeek and other LLMs, it enables one‑protocol unified access.
